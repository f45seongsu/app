1PEAK500이란?

Series 3 프로그램의 최종 퍼포먼스 벤치마크 이벤트

F45 PEAK500은 회원이 5분씩 5개 스테이션을 순환하며, 각 스테이션에서 최대 100점(=100 reps 또는 100 cal)까지 점수를 쌓아 총 500점을 목표로 하는 벤치마크 이벤트입니다.

진행일: 2026년 9월 12일(토) — 클래스는 레이스트랙(Racetrack) 형식, 스테이션 순서는 1(바이크)→2(데빌스프레스+런지)→3(스키)→4(셔틀+스러스터)→5(로워)입니다.

코칭 포인트 (Hybrid Performance Focus)
  • 중량 운동: 웨이트를 바닥에 던지듯 내려놓지 않도록 지도
  • 셔틀 스프린트: 회원 간 충분한 간격(spacing) 확보
  • 에르그 머신: 스테이션 이동 시 반드시 퍼포먼스 모니터(PM) 리셋

사전 준비: '무브먼트 스탠다드' 영상 숙지, 앱 내 각 동작 '코칭 큐' 리뷰, 회원용 '웨이브 시트' 출력. 기록은 앱 또는 인쇄용 스코어카드 중 편한 방법 사용.

3스코어링 시스템

목표는 5개 스테이션 합산 500점

  • 5분(work set)이 끝나면 회원은 달성한 총 렙 수 또는 칼로리를 앱 Assessments 섹션(또는 인쇄용 스코어카드)에 기록
  • 스테이션당 최대 획득 점수는 100점
  • 100점에 먼저 도달하면 그 시점에서 멈추고 남은 시간(remaining time)을 기록
  • 5개 스테이션 모두 100점을 달성하면, 남은 시간을 모두 합산해 총점에 가산 점수로 더함

스코어링 예시

Example A — 렙 스코어 (100점 미도달)
Station 1100 cal | 0:40 남음
Station 278 reps
Station 391 cal
Station 470 reps
Station 5100 cal | 0:10 남음
총점439 (100점 미달성 스테이션은 남은시간 가산 없음)
Example B — 타임 스코어 (전 스테이션 100점 달성)
Station 1100 cal | 0:40
Station 2100 reps | 0:07
Station 3100 cal | 0:17
Station 4100 reps | 0:15
Station 5100 cal | 0:10
총점500 + 1:29 (남은시간 전부 합산 가산)

4플로어 셋업 & 장비 배치

10 stations 레이스트랙 형태

정정: 이전 버전에 있던 "30명, 스테이션당 3명"은 Threshold/Down Under 클래스(Series 3)의 스펙을 잘못 가져온 것입니다. PEAK500 공식 정원은 시간당 27명이며, 동시 플로어 인원수(스테이션당 몇 명이 함께 도는지)는 원본 자료에 별도로 명시되어 있지 않습니다. 각 웨이브(솔로/페어 단위)가 순차적으로 5개 스테이션을 함께 순환하는 구조로 이해하시면 됩니다.
구역장비/배치
Station 1 (하단 우측)Bike Erg 3대 (B B B)
Station 2 (중앙)덤벨 랙 — 남성 12.5kg/28lbs x2, 여성 8kg/18lbs x2 (Classic 기준 배치)
Station 3 (하단 좌측)Ski Erg 3대 (S S S)
Station 4 (상단, 좌→우 이동)셔틀런 거리 마커 + 바벨 랙(남성 블랙 플레이트, 여성 블루 플레이트 — Classic 기준)
Station 5 (상단 우측)Rower Erg 3대 (R R R)
셔틀런 거리 마커 3가지 옵션 (모두 총 이동거리 300m로 동일):
  • 15m × 20회 = 300m
  • 10m × 30회 = 300m
  • 7.5m × 40회 = 300m

스튜디오 공간 폭에 맞춰 셋 중 하나를 선택하면 됩니다 — 방이 좁으면 7.5m×40, 넓으면 15m×20 마커를 사용하세요.

실제 운영 시 Open/Classic 카테고리에 따라 플레이트 색상·중량이 달라지므로(스테이션 상세표 참고), 웨이브 시작 전 회원의 카테고리를 확인하고 해당 무게를 미리 세팅해두세요.

코치가 3명뿐이라면 Wave Coordinator가 순회하며 판정을 겸하고, 회원이 스스로 기록하는 에르그 스테이션(1·3·5)은 상대적으로 자율 운영이 가능하므로 근력 판정이 필요한 2·4번 스테이션에 우선 배치하세요.
판정 기준 관련 안내: 원본 자료(툴킷)에는 "코치가 2·4번 스테이션에서 저지 역할을 한다"는 것만 명시되어 있고, 데빌스프레스·런지·스러스터의 구체적인 굿렙/노렙 판정 기준(가슴 터치 라인, 무릎 각도, 페어 싱크로 일치 기준 등)은 별도로 문서화되어 있지 않습니다. 클래스 전 코치 전원이 Movement Standards 영상을 함께 시청하고 판정 기준을 사전에 맞춰두는 것을 권장합니다.

7웨이브 캐패시티 & 시간표

클래스 정원 27명 · 6분 간격 웨이브

  • 클래스 정원: 27명 (최대)
  • 웨이브 간격: 클래스 시작 시각부터 6분마다 새 웨이브 투입
웨이브 수 관련 두 자료 수치 차이 주의
스케줄링 가이드 원문은 "1시간 슬롯당 6분 간격으로 최대 10웨이브"라고 안내합니다 (60분÷6분=10). 반면 PEAK500 툴킷의 Wave Capacity Guide는 "Waves Per Hour: 9" + "Built-in-Buffer"로 명시합니다.
→ 실제 운영 시에는 9웨이브를 채우고 마지막 1슬롯(6분)을 버퍼로 비워두는 방식을 기본으로 하세요. 지연·부상 대응 등 여유시간 확보 목적입니다.

8Mindbody 스케줄링 설정

  • Mindbody에서 F45 PEAK500 클래스는 1시간 단위로만 등록 (그보다 크거나 작은 단위 금지). 클래스 정원 27명.
  • 'Show to Public' 설정은 반드시 OFF(체크 해제) 상태 유지 — PEAK500의 페어 예약 기능이 정상 작동하기 위한 필수 조건입니다.
  • 연습용(Practice-run) 클래스를 열고 싶다면 MBO에서 F45 PEAK500 Practice 클래스로 별도 등록하세요.
  • 'Wave Time Registrations' 사인업 시트와 PEAK500 toolkit(F45 PEAK500 Playbook 폴더 내)을 활용해, 회원을 웨이브 시간대별로 수기 배정합니다.
Show to Public 미해제 시 발생 문제: 페어 예약(파트너 초대) 기능이 정상적으로 지원되지 않습니다. 클래스 오픈 전 반드시 재확인하세요.

9회원 예약(Booking) 플로우

앱 버전 4.1.5 이상 필요

① 기본 예약 흐름 (Primary Member Invitation Send Flow)

  1. 회원이 앱에서 Book 탭 → 해당 날짜(9/12)의 PEAK500 클래스 시간대에서 “+” 버튼 클릭
  2. "How would you like to compete?" 화면에서 Individual(개인) 또는 Pair(페어) 선택
  3. Pair 선택 시 "Enter Partner's Email" 화면에서 파트너 이메일(F45 앱 로그인 이메일) 입력 → BOOK NOW
  4. 예약 완료 화면(CLASS BOOKED)이 뜨고, 해당 시간대 예약 목록에 반영됨. 해당 클래스/시간대는 파트너를 위해 48시간 동안 자리가 hold됨

② 파트너 초대 수락 흐름 (Partner Invitation Acceptance Flow)

  1. 파트너는 "F45 PEAK500 Pair Competition Invite" 이메일 수신 (예: "Juddy has invited you to partner with them on [날짜] at [시간] for the F45 PEAK500 class... 48시간 내 예약하지 않으면 자리가 해제됩니다")
  2. 기존 회원이면 앱 Book 화면에서 동일 클래스 시간대로 이동 → 해당 시간대에 "Join [이름]" 표시 확인 → “+” 버튼으로 예약 확정
  3. 비회원이면 이메일 안내에 따라 앱 다운로드 → Book 섹션에서 해당 날짜 선택 → 해당 시간대(하이라이트 표시) 예약 → 동일 스튜디오·클래스 시간 온보딩 진행 → 온라인 결제 옵션 제시
  4. Mindbody 상에서는 페어 예약도 개인 예약과 동일하게 표시됩니다.
코치가 알아둘 점: 파트너가 48시간 내 확정하지 못하면 예약이 자동 해제될 수 있으니, 예약 마감 임박 회원에게는 파트너 확정을 안내해주세요.

10어세스먼트(기록) 제출 방법

부킹(예약)과 어세스먼트(기록 제출)는 서로 별개의 과정입니다

  1. 앱에서 Track > Assessments > Start an Assessment > F45 PEAK500 (Featured Assessments 항목) 경로로 이동
  2. "Choose Your Assessment Type" 화면에서 Individual(개인) 또는 Partner(페어) 선택
  3. Partner 선택 시 파트너의 F45 앱 로그인 이메일 입력 (Skip for now도 가능)
  4. 완료 후 F45 PEAK500 어세스먼트 화면에서 5개 운동(Bike erg, DB Devils Press+DB Suitcase Forward…, Ski erg, 15m Shuttle Runs+Wall balls, Row erg) 항목별 기록 입력, 하단에 연결된 파트너 표시
중요: 페어로 부킹하지 않았더라도 언제든 페어 어세스먼트를 시작/연결할 수 있습니다. 부킹 시 이미 페어 초대를 보냈다면 어세스먼트 화면의 이메일란이 자동완성됩니다.

세부 규칙

  • 초대받은 파트너는 해당 어세스먼트를 보거나 수정할 수 없으며, 오직 처음 초대를 보낸 회원만 편집 가능 (파트너 화면에는 "DELETE ASSESSMENT" 옵션만 노출)
  • 초대받은 파트너에게는 "본인이 어떤 회원의 어세스먼트에 연결되었다"는 알림 이메일이 발송됨
  • 한 파트너가 여러 어세스먼트에 연결된 경우, 가장 최근에 제출된 어세스먼트가 리더보드에 반영됨

13PEAK500 이해에 필요한 최소 용어

용어정의
Members (멤버)동시에 운동하는 회원 수 (PEAK500: 클래스 정원 시간당 27명. 스테이션당 동시 인원수는 원본 자료에 별도 명시 없음)
Stations (스테이션)운동 종목의 수 (PEAK500: 5개)
Work / Rest운동 시간 / 휴식 시간 (PEAK500: 스테이션당 Work 5분. 웨이브가 6분 간격으로 투입되므로 나머지 최대 1분은 이동/전환 시간으로 추정되나, 원본 자료에 "1분 Rest"로 명시된 문구는 없음 — 확정 규정 아님)
Racetrack (레이스트랙)스테이션이 방을 원형으로 순환하며 서로 연결되는 무브먼트 시스템 — PEAK500이 이 형식
Pod (팟)일정 수의 스테이션을 포함하는 워크아웃의 한 구역 (PEAK500: 1개 팟, 5개 스테이션)
Wave (웨이브)같은 시간 슬롯 안에서 순차적으로 투입되는 참가 그룹 단위 (PEAK500 핵심 운영 개념)

14PEAK500 워크아웃 인트로 스크립트

레이스트랙 형식 템플릿에 PEAK500 값을 채운 버전

HEY TEAM! Welcome to F45! My name is Coach ___ and this is Coach ___.
Today's workout is PEAK500, a 하이브리드(에르그+웨이트+스프린트) workout with one Pod, 5 stations in a Racetrack format.
To all of our newcomers, welcome to the team!
The timing for PEAK500 is 각 스테이션당 5분 동안 최대한 많은 렙/칼로리를 쌓는 방식이며, 1 set(s) at each station, 1 lap을 통해 5개 스테이션을 모두 순환합니다.
스테이션당 최대 100점, 5개 스테이션 합쳐 500점이 목표입니다.
If you have any injuries or need any modifications, please let us know during the warm-up!
To recap: 스테이션당 5분, 1 lap, 목표는 500점. 오늘 하루 파이팅해봅시다!

15PEAK500 당일 코치 체크리스트

  • Mindbody에서 'Show to Public'이 OFF(체크 해제) 상태인지 재확인
  • Movement Standards 영상 사전 시청 완료
  • 각 동작의 앱 내 '코칭 큐' 리뷰 완료
  • Wave Time Sheet 출력 및 웨이브별 회원 명단 배정 (9웨이브 + 마지막 버퍼 슬롯 확보)
  • 인쇄용 Score Card v1.2 준비 (앱 기록이 어려운 회원 대비)
  • 플로어 셋업: 1~5번 스테이션 순서(레이스트랙)로 장비 배치, 셔틀런 마커 거리(15m/10m/7.5m 중 공간에 맞게) 확정
  • Open/Classic 카테고리별 플레이트·중량 사전 세팅
  • 웜업존 지정 및 웜업 루틴(쿼드풀·암서클·카프레이즈) 준비
  • 코치 역할 배정: Wave Coordinator 1명 + Station 2·4 Judge (근력 스테이션 우선 배치)
  • 에르그 머신 스테이션 이동 시 PM(퍼포먼스 모니터) 리셋 안내
  • 중량 운동 시 웨이트 던지지 않기, 셔틀 스프린트 시 충분한 간격 확보 강조
  • 회원에게 페어 참가 시 파트너 확정(48시간 이내) 리마인드
  • 리더보드(앱/TV/웹포털) 노출 원치 않는 회원에게 정보 제거 옵션 안내
  • 레이스트랙 형식 인트로 스크립트로 워크업 브리핑 진행
